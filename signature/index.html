Putting it in Gmail

  1. Open a signature page above and hit Copy on the one you want.
  2. Gmail → Settings → See all settings → Signature.
  3. Create or select a signature, click into the box, and paste with ⌘V. Do not use "paste and match style" — that strips the layout.
  4. Set it as the default for new emails and replies, then Save changes at the bottom.
  5. Send yourself one test from the phone app to confirm the images load.

Apple Mail: paste into a new signature in Preferences → Signatures and uncheck "Always match my default message font."
